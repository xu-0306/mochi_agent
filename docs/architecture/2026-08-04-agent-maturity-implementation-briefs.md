## Global stop conditions

- Do not dispatch a worker package until all dependencies are integrated and its consumed contracts are frozen by Main.
- Do not dispatch while a package has overlapping same-wave ownership or exceeds degraded one-production/one-test limits.
- Stop dispatch and recompute MAP-EXECUTION-SCHEDULE-V1 when a dependency, owner, package, contract join, host slot count or calibrated duration changes; never treat the reference unit schedule as a calendar promise.
- Stop and replan if any worker requires shared lifecycle, persistence, migration, authorization, security, concurrency, transport or producer/consumer seam changes.
- Stop if a gate lacks an executable oracle or if a critical invariant would rely only on planner-authored evidence.
- Do not modify, stage, clean or overwrite mochi/runtime/sandbox/linux.py or tests/security/test_os_sandbox.py.
- Actual subagent creation is outside this planning turn and requires a later explicit user instruction.

## Fallback

- Mode: `main_takeover`

- shared contract changes after freeze

- model identity remains unavailable and package cannot be reduced safely

- reference schedule is stale or actual worker capacity cannot satisfy its declared slot assumptions
- worker reports blocked with evidence showing an unowned seam
